# Binary Thinking: C++ & Windows

Учебный проект курса **Binary Thinking: C++ & Windows**  
Спикер: **Алексей Никольский** (Мастерская системного программирования ИТМО)

Курс для тех, кто хочет понимать, как работает код: от исходников C/C++ до машинных инструкций, структуры памяти процесса, Windows Internals, reverse engineering, hooking, injection и драйверов.

---

## О проекте

В рамках курса реализован порт **DOOM** с интеграцией **Stable Diffusion** (на базе [stable-diffusion.cpp](https://github.com/leejet/stable-diffusion.cpp) — последняя версия с GitHub).

На данный момент пройдены модули:
- **FOUNDATION** (2–6 ноября) — путь кода от исходника до runtime и reverse engineering
- **WINDOWS** (9–13 ноября) — программирование под Windows, архитектура системы, hooking, injection, код ядра

Планируются:
- **C++** (7–11 декабря) — C++ с нуля, OOP, шаблоны проектирования, внутреннее устройство языка
- **ADVANCED** (14–18 декабря) — драйверы Windows, эксплойты, организация проектов

Формат: гибридный (аудитория + KTalk), 19:00–22:00.

## Возможности

- Классический геймплей DOOM
- Генерация изображений с помощью Stable Diffusion прямо из приложения (текстуры, спрайты, окружение и т.д.)
- Практика работы с бинарями, отладкой, reverse engineering и Windows API
- Примеры по компиляции, линковке, многопоточности, памяти и системному программированию

## Требования

- Windows 10 / 11 (x64)
- Visual Studio 2022 (Desktop development with C++)
- Рекомендуется: CMake, Windows SDK

Для Stable Diffusion:
- Модель (например, SD 1.5 `.safetensors` или `.gguf`)
- Достаточно оперативной памяти (минимум 8–16 ГБ в зависимости от модели)

## Сборка

1. Клонируйте репозиторий:
   ```bash
   git clone <your-repo-url>
   cd <repo>
   ```

2. Откройте `solution/solution.sln` в Visual Studio.

3. Выберите конфигурацию **Debug | x64** (или Release).

4. Соберите решение (Build → Build Solution).

5. Запустите `doom_app`.

> **Примечание.**  
> Папка `stable-diffusion.cpp` уже содержит последнюю версию с GitHub. При необходимости обновите её самостоятельно.  
> Модели Stable Diffusion нужно скачать отдельно и положить в ожидаемую папку (см. код `doom_app` / документацию).
